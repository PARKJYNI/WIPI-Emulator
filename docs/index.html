기능 · Features

📟 3가지 플랫폼 지원

WIPI(KTF·LGT), SKVM(SKT), J2ME 형식의 한국 피처폰 게임을 실행합니다. Runs WIPI, SKVM and J2ME games.

📂 간단한 게임 추가

+ 버튼으로 보유한 게임 파일(.zip/.jar)을 가져오면 표지와 이름이 자동 표시됩니다. Import your own game files.

💾 게임별 세이브

세이브는 게임별로 안전하게 보관됩니다. Per-game save data, kept on your device.

🎵 사운드 & 진동

배경음악(MIDI)과 효과음, 진동까지 원작 그대로. BGM, sound effects and haptics, faithful to the originals.

🎮 키패드 · 컨트롤러 · 키보드

화면 키패드는 물론 게임 컨트롤러와 하드웨어 키보드도 지원합니다. On-screen keypad, gamepads and keyboards.

🔒 완전 오프라인 · 무수집

계정도, 광고도, 데이터 수집도 없습니다. No accounts, no ads, no data collection — fully offline.

자주 묻는 질문 · FAQ

게임은 어떻게 추가하나요? / How do I add a game?

라이브러리 화면의 + 버튼을 눌러 보유하신 게임 파일(.zip, .jar)을 선택하세요. 표지와 이름이 자동으로 표시됩니다.

Tap the + button in the library and pick a game package you own. The cover and title appear automatically.

게임이 포함되어 있나요? / Does the app include games?

아니요. 앱에는 게임이 포함되어 있지 않으며, 보유하신 게임 파일을 직접 가져와야 합니다.

No — the app ships without game content. You import files you own.

어떤 게임이 지원되나요? / Which games are supported?

WIPI(KTF/LGT), SKVM(SKT), J2ME 형식을 지원하며, 호환성은 업데이트마다 개선됩니다. 안 되는 게임이 있으면 게임 이름과 오류 화면을 보내주세요 — 실제 사용자 제보로 여러 게임이 고쳐졌습니다.

Compatibility improves with every update. If a game doesn't work, email us the game name and an error screenshot — user reports have already fixed several titles.

세이브는 어디에 저장되나요? / Where are my saves?

게임별로 앱 내부 저장공간에 보관됩니다. 라이브러리에서 게임을 삭제하면 해당 세이브도 함께 삭제됩니다.

Per game, inside the app's own storage. Deleting a game also deletes its saves.
